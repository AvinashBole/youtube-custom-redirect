CHROME INSTALL
1. Unzip YouTube-Custom-Redirect.zip.
2. Open chrome://extensions and enable Developer mode.
3. Click Load unpacked and select the youtube-custom-redirect folder (the folder with manifest.json).
4. Click the extension icon > Open settings.
5. Enter a destination URL such as https://example.com/watch?v={videoId} or a fixed URL such as https://example.com, then Save.
6. Reload YouTube tabs that were already open.

BEHAVIOR
Redirects clicks on standard YouTube videos, Shorts and /live/ links, plus directly opened video pages and YouTube in-app navigation.
Leave the destination blank to keep redirects off. Pause redirects by unchecking Enable redirects in Settings.

FIREFOX
Firefox's temporary add-on loader under about:debugging > This Firefox > Load Temporary Add-on can load the manifest.json from this folder. Firefox compatibility can vary by version.
